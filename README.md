# 📖 Dictionary and Word Lookup App

A simple web-based dictionary application that allows users to search for English words and view their meanings, parts of speech, examples, and pronunciation.

## ✨ Features

- 🔎 Search for English words
- 📚 Display word definitions
- 🏷️ Display parts of speech
- 💡 Display example sentences when available
- 🔊 Pronunciation using browser speech synthesis
- ❌ Error message for unavailable words
- ⌨️ Press Enter to search
- 📱 Responsive design

## 🌐 API

The application uses the **Wiktionary REST API** to retrieve dictionary definitions and related information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Fetch API
- Wiktionary REST API
- Web Speech API
